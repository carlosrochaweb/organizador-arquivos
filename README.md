# organizador-arquivos
Criei um organizador simples de arquivos em python, com base no tipo de cada arquivo. O script roda e organiza em pastas específicas conforme o tipo do arquivo.

Criei esse script com o objetivo de começar os estudos em python.

Basicamente o script organiza aqueles arquivos que estão perdidos no seu computador, se você tem documentos, pdf, videos, imagens espalhadas pelo seu computador esse script vai ajudar a organizar os arquivos nas pastas correspondentes.

Ele usa as bibliotecas OS e SHUTIL

Como funciona?
    - Você coloca o caminho da pasta que necessita na variável caminho_alvo
    - Você pode mudar as categorias, adicionar novas extensões de arquivos ou mudar o nome das pastas destinos
    - O script ignora as pastas e considera apenas os arquivos, separa aqueles cuja as extensões constam nele e coloca em suas respectivas pastas.
    - Você executa o código no terminal e de forma rápida ele fas a separação dos arquivos.

Basicamente é assim que funciona
